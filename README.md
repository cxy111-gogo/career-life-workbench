# 求职生活成长工作台

移动端优先的 PWA 静态网页，用于规划 2028 年研究生求职、记录生活运营状态、定期自我提升复盘。

## 当前阶段

- 交付形态：单页 HTML + PWA manifest + Service Worker
- 数据能力：浏览器 localStorage 本地持久化，支持 JSON 导入/导出；保留云同步接口占位
- 适配：手机访问、添加到桌面、离线打开

## 启动 / 检查

```bash
npm run check
npm run build
```

## 部署

优先使用 frontend-cloud：

```bash
npx -y --registry https://npm.corp.kuaishou.com @codeflicker/frontend-cloud-cli@latest deploy --project-id career-life-workbench --project-name "求职生活成长工作台" --dir .
```

如部署 CLI 缺少登录态，请先执行：

```bash
appwrite-cf login-ks
```

## 同步说明

当前版本默认本地优先。跨设备实时同步需要接入 Appwrite 或其他云端数据库；页面中已经提供「同步 / 导入导出」入口，后续可把 `syncStatus` 相关逻辑替换为云端读写。

## 功能清单

- 求职难点：企业岗位、公考、省考、选调、事业编、中职教师、人才引进等事项追踪。
- 生活运营：健身、睡眠、补水、情绪、生理期等状态记录。
- 自我提升：财商、情商、亲密关系执念复盘。
- 同步与归档：本地自动保存，支持 JSON 备份导入/导出。
- 手机体验：PWA manifest、Service Worker、移动端抽屉导航、可添加到桌面。
