Sync Archive

同步、归档与手机使用

当前版本
静态网页 + 本地浏览器保存。网页内容直接写在 HTML 中，打开不会再只剩标题。新增记录会保存在当前浏览器 localStorage，可导出 JSON 备份。
手机添加到桌面
用 Safari / Chrome 打开 GitHub Pages 链接，选择“添加到主屏幕”。如果之前添加过旧版，建议先删除旧桌面图标，再重新添加。
跨设备同步限制
GitHub Pages 是静态站，手机和电脑不会天然同步本地新增记录。短期用导出/导入备份；后续可接 Supabase / Firebase 做云同步。
缓存处理
如果打开还是旧版，在链接后加 ?v=stable-20260825，或清除浏览器缓存。PWA 缓存很倔，别跟它讲道理，直接换版本号。
